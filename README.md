# FácilTicket Web

Web comercial independiente de `app.facilticket.es`, construida con Python y Flask para desplegarse en Easypanel.

## Desarrollo

1. Crea un entorno virtual.
2. Instala `requirements.txt`.
3. Ejecuta `flask --app wsgi run --debug`.

Consulta `.env.example` y nunca subas `.env` ni credenciales. La publicación queda bloqueada hasta completar textos legales, contacto, capturas y confirmaciones funcionales.
